# Demo provenance

The PNG is a screenshot of this plugin version running in an isolated official BB 0.47.1 installation. All thread titles, messages and states are synthetic. No provider credentials or real agent runs were used.

`columns.png` shows a parent named Release planning, a pending question (Choose the accent color), and a failed example (Check the preview build). Responsibilities and the badges plugin are absent. The chats and composers are real BB components. Open the parent with `columns=auto` to show both descendants; the screenshot uses the default limit of eight.
