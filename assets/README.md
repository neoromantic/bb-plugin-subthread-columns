# Demo provenance

`columns.png` is an unmodified screenshot of official BB 0.47.1, captured on 31 October 2026 in an isolated disposable runtime. All titles, messages and states are synthetic. No provider credentials or real agent runs were used.

Only Subthread Columns 0.1.0 was active, from public release commit [`b40723a771e201051b48a6bff256554898450a19`](https://github.com/neoromantic/bb-plugin-subthread-columns/tree/b40723a771e201051b48a6bff256554898450a19). Responsibilities, Model & Effort Badges and True Colors were absent. The sidebar marks are BB’s own.

The parent Release planning appears beside a real question form (Choose the accent color) and a failed example (Check the preview build), each with BB’s chat and composer. Settings: `columns=auto`, `maxColumns=8` (defaults). Dark theme, 1840×1150 CSS pixels at 2× scale; PNG 3680×2300. No crop, resize or UI redraw.
